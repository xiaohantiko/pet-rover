# 寻宠小车 · Pet Rover

**0.1.0 工程原型** · 不用买硬件即可试手机控制、寻宠和返航流程。仿真、真实视频处理和 ESP32 台架刻意隔离；这不是已通过家庭无人值守验收的成品固件。

## 第一次试：先当驾驶员

下载源码并解压，打开所在目录的终端，执行 `python3 rover_sim.py`，打开终端打印的完整地址。点 **取得驾驶权 → 寻找模拟猫 → 查看记录 → 注入低电测试**。无需账号、无需安装 Python 第三方库。两台设备体验、局域网使用、重启和常见问题见 [操作手册](RUNBOOK.md)。

| 你想体验什么 | 入口 | 边界 |
|---|---|---|
| 网页遥控、驾驶权、共享事件、急停与返航 | [仿真控制台](RUNBOOK.md) | 虚拟地图、运动、猫和电量；不输出电机指令 |
| 手机预览、下载一帧 | [独立摄像预览](camera_preview.py)，见操作手册末节 | 首次默认测试图；USB/CSI 需另接相机 |
| 从真实视频识别猫狗、选图、生成事件短片 | [本地宠物日记](media/README.md) | 输入本地文件，不自动调用家庭摄像头 |
| 安全控制、测距和蓝牙台架 | [固件说明](firmware/README.md) | 默认无运动，只允许指定架空试验 |
| 音频收发 | [语音台架](audio/README.md) | 单独授权，不常开麦克风 |
| 深度视觉近障判断 | [只读视觉模块](vision_guard/README.md) | 需要已标定的毫米深度图；单目夜视相机不是深度相机。只给出近障、未见近障或未知，不授权运动 |
| 地图导航和回桩任务接口 | [导航适配](navigation/README.md) | 实机须独立安装并验收定位、驱动和充电反馈 |

## 验证、更新与隐私

```sh
python3 -m unittest discover -s tests -v
python3 scenario_report.py
```

详见 [版本记录](CHANGELOG.md)。更新前停止服务，备份事件库，保留旧版本；下载新版本到另一个目录，先运行测试图和仿真，确认后再切换。上板程序不要与桌面软件联动自动升级。本库只放代码和软件使用说明，不收集家庭影像，也不含采购、加工图、实物接线或私人验收记录。请不要在公开 issue 上传家庭地图、口令和含人物的录像。
