# 深度视觉近障证据（只读）

这个模块回答的是：“在**已标定相机的指定视野**里，是否有成片的近距离深度回波？”它不连接电机，不输出速度，不规划绕行，也不以相机单独授权前进。它不是把普通 RGB 摄像头变成测距仪；硬件使用需要同步标定的双目、RGB-D 或其他能给出米制深度图的设备。**本次测试全部是合成深度数值，不是实物视觉避障实测。**

## 零硬件运行

在公开仓库目录运行：

```sh
python3 vision_guard/depth_guard.py
python3 -m unittest discover -s tests -p test_vision_guard.py -v
```

内置三个 16×12 的虚构深度帧：远处平面得到 `clear`；前方 2×2 近障得到 `stop`；局部盲区得到 `unknown`。每个结果均附有效深度覆盖率、最差分区覆盖率、最近有效深度、最大四连通近障像素数，且 `motion_authorization` 永远是 false。这里的 400 mm、4 像素等只是让人能复现实验的数值，不是适用于真实车速、焦距或传感器的门槛。

| 输出 | 判定与含义 |
|---|---|
| `stop` | ROI 内相邻的近深度像素构成足够大的四连通簇；即使画面另一区域无效，也保留这个明确的近障证据 |
| `unknown` | 空洞太多、局部盲区、零值/NaN/超量程导致覆盖不足、存在低于有效近限的非零数值、零散近回波不足以确认为簇、形状/设备不匹配或帧太旧等，不应解读为无障碍 |
| `clear` | 在可用覆盖门槛内没有观察到近回波。**不是道路一定安全**；允许的少量空洞内仍可能有细物体。负障碍（台阶、楼梯）、ROI 外障碍和动态闯入不受保证 |

## Python 接口和标定

```python
from vision_guard.depth_guard import Calibration, classify

cal = Calibration("synthetic_depth", 16, 12, 16, 16, 7.5, 5.5,
                  (2, 2, 14, 11), 100, 400, 3000, 4, 200)
depth_mm = [[1200] * 16 for _ in range(12)]
observation = classify(depth_mm, cal, camera_id="synthetic_depth", age_ms=0)
print(observation["state"])
```

输入是**经过畸变校正的光轴深度 Z**，单位固定为毫米，按 `[行][列]` 访问。若设备给的是米、逆深度、视差或沿光线的斜距，须用正确标定和模型转换，不能只改字段名。此模块不替代标定/视差计算。提供与该设备、校正配置、当前分辨率一致的 `camera_id` 和针孔内参 fx、fy、cx、cy；换分辨率、镜头或安装姿态后须重建配置。相机系 x 向右、y 向下、z 向前，输出的簇样本是摄像头坐标，不是机器人坐标。

`roi=(左,上,右,下)` 为左上包含、右下不含的像素边界。用相机安装高度/俯仰、车辆实际外廓、刹停包络与短距盲区，实测选择包含前方行驶走廊的 ROI；本实现不剔除地面、不处理坡度。ROI 越大越易把地面当障碍，越小越易遗漏低矮或侧向目标。将 ROI 分成 4 列×3 行，分别计算覆盖；`min_coverage` 和 `min_tile_coverage` 控制全局和每块门槛。`min_mm/max_mm` 根据厂家标定量程，`stop_mm` 与 `min_cluster` 需要用不同距离/尺寸、制动余量实测。无效的标定配置直接抛异常；集成方当 `unknown` 处理，不得沿用上一帧的 clear。

集成时应从**可信的采集时钟和接收时钟**算出真实 `age_ms`；不同设备时钟必须正确映射。必须另设独立定时器检测没有新帧的情况；若根本没有调用 `classify`，这个纯函数不可能感知掉线。不要从网络请求或恒定传 0 获得新鲜度。低光、镜面/透明表面、黑毛、细线会导致深度错失；红外补光可能干扰主动深度。即使测得 clear 也必须保留独立近距、碰撞、防跌落和本地驱动保护。

## 私有数据离线重放

从采集程序导出配置 JSON（与 `Calibration` 字段同名）和帧 JSON：

```json
{"camera_id":"synthetic_depth","width":16,"height":12,"fx":16,"fy":16,"cx":7.5,"cy":5.5,"roi":[2,2,14,11],"min_mm":100,"stop_mm":400,"max_mm":3000,"min_cluster":4,"max_age_ms":200}
```

帧 JSON 的 `camera_id` 必须相同，`age_ms` 应为**记录采集时的真实帧龄**，`depth_mm` 为完整 12 行×16 列的数值数组。JSON 空值用 `null` 表示无效样本。运行 `python3 vision_guard/depth_guard.py --calibration /私有路径/cal.json --frame /私有路径/frame.json` 仅离线重放，不代表此刻的环境。不要将家庭深度图或设备标识上传公开库。

装车前先固定车体、隔离电机，在不同距离摆放纸箱、小障碍、细线、空场和反光区域，记录真值、帧龄、输出及误报/漏报；遮住镜头、停止数据流、改变分辨率检查降级逻辑。未完成实测前，预设没有任何导航安全等级。若判定不可靠，应降低速度并依赖整车安全架构，不应通过放宽阈值来“通过测试”。
